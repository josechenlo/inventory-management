Data Flow — User Changes a Filter

User selects a filter in FilterBar.vue
v-model writes to a shared ref in useFilters.js — a module singleton, so every view sees the change.
View reacts via watch()
Each view watches the relevant filter refs and calls its loader (e.g. Inventory watches location + category only).
API client builds the request
getCurrentFilters() maps UI state to params (location→warehouse); api.js drops any value equal to 'all'.
FastAPI filters in memory
Route runs apply_filters() / filter_by_month() over the in-memory list and validates against a Pydantic response model.
Response assigned to a ref
The JSON array is written to the view's data ref (.value), triggering reactivity.
Computed properties derive & render
Client-side computed applies search text, sorting and status classes; the template re-renders reactively.
